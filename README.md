## 🏗️ Общие требования и зависимости

Для сборки и запуска всех проектов вам понадобятся:
* Компилятор `gcc` или `clang`
* Наличие утилиты `make` (если планируется автоматизация сборки)
* Библиотека **ncurses** (используется в интерактивном Pong и Game of Life)

### Установка ncurses в Ubuntu/Debian/WSL:
```bash
sudo apt update
sudo apt install libncurses5-dev libncursesw5-dev

```

## 🎮 1. Classic Pong (`pong.c`)

Классическая пошаговая игра для двух игроков. Особенность этой версии — пошаговый режим ввода (для продвижения мяча игрокам нужно совершать действия или пропускать ход клавишей `ENTER`). Игра продолжается до **21 очка**.

### Сборка и запуск

```bash
gcc -Wall -Werror -Wextra pong.c -o pong
./pong

```

### Управление

* **Игрок 1 (Слева):** `A` (вверх) / `Z` (вниз)
* **Игрок 2 (Справа):** `K` (вверх) / `M` (вниз)
* **Пропуск хода:** `Пробел` или `ENTER`

## 🕹️ 2. Interactive Pong (`pong_interactive.c`)

Модифицированная версия игры Pong, переписанная с использованием библиотеки `ncurses`. Игра работает в **реальном времени** независимо от пользовательского ввода (мяч двигается автоматически с фиксированной задержкой кадров). 
### Сборка и запуск

```bash
gcc -Wall -Werror -Wextra pong_interactive.c -o pong_interactive -lncurses
./pong_interactive

```

### Управление

* **Игрок 1 (Слева):** `A` (вверх) / `Z` (вниз)
* **Игрок 2 (Справа):** `K` (вверх) / `M` (вниз)
* **Выход из игры:** Любая другая клавиша (кроме системных)

## 🧠 3. Conway's Game of Life (`game_of_life.c`)

Реализация знаменитого клеточного автомата Джона Конвея «Игра „Жизнь“» в консольном интерфейсе ($80 \times 25$). Поле является зацикленным (тороидальным) — крайние ячейки граничат с противоположными краями поля.

Программа считывает начальное состояние матрицы («карту жизни») из стандартного потока ввода `stdin`, после чего переинициализирует терминал для динамического отображения симуляции с помощью `ncurses`.

### Сборка и запуск

Игра требует передачи начального файла конфигурации (где `1` — живая клетка, `0` — мертвая).

```bash
# Компиляция
gcc -Wall -Werror -Wextra game_of_life.c -o game_of_life -lncurses

# Запуск с передачей файла конфигурации (вместо 'preset.txt' укажите ваш файл)
./game_of_life < preset.txt

```

### Управление скоростью симуляции

Вы можете изменять скорость эволюции поколений прямо во время работы программы:

* `A` / `a` — Увеличить скорость (уменьшить задержку между кадрами)
* `Z` / `z` — Уменьшить скорость (увеличить задержку между кадрами)
* `Пробел` —  Выйти
